# 🚀 AI-Powered Instagram Analytics & Growth Strategist

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://instagram-analytics-expert.streamlit.app/)
An intelligent, Streamlit-based web application that acts as an elite Instagram Growth Strategist. It leverages **Google Gemini API** to analyze post performance, generate viral hooks/captions, and extract growth insights from screenshots.

## ✨ Key Features

- **📊 Analytics Analyzer:** Input backend metrics (reach, impressions, saves, shares) to get a professional AI breakdown, a quick TL;DR summary, and actionable steps for your next post.
- **🎯 Viral Hook & Caption Generator:** Generate scroll-stopping video hooks, high-converting captions, and targeted SEO hashtags based on your topic and tone.
- **📸 Screenshot Content Analyzer:** Upload screenshots of posts or dashboards to reverse-engineer competitor content and generate fresh hook ideas.
- **🌍 Multi-Language Support:** Generate reports and strategies in your preferred language.
- **🛡️ Secure Configuration:** Uses Streamlit Secrets (`st.secrets`) to keep API keys safe and secure.
- **⚡ Smart Error Handling:** Built-in exception handling for API rate limits (HTTP 429) to ensure a smooth user experience.

## 🛠️ Tech Stack

- **Frontend/UI:** Streamlit
- **AI Engine:** Google Gemini API (`gemini-3.6-flash`)
- **Data Processing:** Pandas, Plotly
- **Language:** Python.
